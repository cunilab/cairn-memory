# 0.1.6 Step 7 — Web console and hardening

Base: steps 3–6 done. Depends on: S§5 (routes marked →7: `/export`, `/diagnose`, `/delete`,
`/graph`, `/projects/{id}/branches|conflicts`), S§3.2 (`GET /memories/{id}` never counts usage),
P§2 of step 6 (`origin`, `stale_cause`, `status_changed_at`, `link` job), step-6 §7.3 audit actions,
F§1.2 `audit_events`. Last step of 0.1.6.

Owner decisions applied: humans use the web for reports and essential tasks only (tokens, setup,
accounts, privacy erase); **no IP limits and no lockouts** that could block Cairn.

## 0. Decisions

| # | Decision | Why |
|---|---|---|
| W1 | Six pages: **Dashboard, Memories, Graph, Projects, Activity, Settings**. `jobs`, `devices`, `accounts` pages fold into Activity and Settings. | Owner list; fewer screens. |
| W2 | `GET /stats` returns every dashboard number; `POST /export`, `GET /diagnose` and the browser-side aggregation are deleted. | A8: the dashboard downloads every memory today. |
| W3 | Human actions kept: create/rotate/revoke device tokens, change/reset password, register accounts (admin), transfer project ownership, forget a memory; plus, per the UX spec §9, export/import of owned memories, project rename and the device setup command. Removed: memory feedback buttons, any merge/close-branch/verify control (guarded by grep), and the admin requeue/discard routes and buttons (jobs are read-only; quarantined jobs retry automatically after an upgrade and after 24 h). | Automation first; agents give feedback. |
| W4 | TS types are generated from Rust with **ts-rs** (feature `ts` on core/store/server, exported by `cargo test`), into `apps/web/lib/generated/`; CI fails on drift. `lib/types.ts` is deleted. | ts-rs is derive-only, honours serde attributes (`rename_all`, `skip`, `flatten`, `untagged`), and adds no runtime code. specta needs a runtime exporter crate and is built around tauri/rspc. |
| W5 | Login takes the same work for unknown email, disabled account and wrong password (one Argon2 verify against a dummy hash). The email rate limiter is deleted; nothing else replaces it. | Owner: no lockouts or IP limits. A11 enumeration. |
| W6 | Stable auth codes: `401 session_required` (web session missing/expired/revoked), `401 invalid_credentials` (login). The web switches on `code`, never on text. | A9. |
| W7 | Cookie lifetime = server `expires_at` (number, epoch seconds) − now; the proxy rejects `.`/`..`/empty path segments and only forwards allowlisted prefixes. | A10, A1. |
| W8 | Components live next to their page (`app/<page>/_components/`); `components/` keeps only the shell and shared widgets. | Owner request; easier deletion. |
| W9 | Web unit tests (`node --test`) run in CI; proxy logic moves to a pure `lib/proxy.ts` so it can be tested without Next. | A13. |

### 1.1 `GET /stats?tz=<minutes east of UTC, -840..840, default 0>` (Web session; `routes/stats.rs` new, `store/src/stats.rs` new)

```rust
#[cfg_attr(feature = "ts", derive(ts_rs::TS), ts(export))]
#[derive(Serialize)]
pub struct Stats {
    pub memories: Counts,
    pub activity: Vec<Day>,          // last 30 local days, oldest first, zero-filled
    pub usage: UsageReport,
    pub stale: StaleReport,
    pub links: LinkReport,
    pub jobs: JobCounts,             // the person's own (admin: all)
    pub projects: i64,               // projects the person belongs to
}
pub struct Counts { pub total: i64, pub by_kind: BTreeMap<String,i64>, pub by_status: BTreeMap<String,i64>,
                    pub by_scope: BTreeMap<String,i64>, pub by_origin: BTreeMap<String,i64> }
pub struct Day { pub day: String /* YYYY-MM-DD */, pub saved: i64 }
pub struct UsageReport { pub never_fetched: i64, pub fetched_30d: i64, pub top: Vec<UsedMemory> /* ≤ 5 */ }
pub struct UsedMemory { pub id: String, pub kind: Kind, pub title: String, pub fetched: i64, pub helpful: i64, pub wrong: i64 }
pub struct StaleReport { pub total: i64, pub feedback: i64, pub missing: i64, pub expiring_30d: i64 }
pub struct LinkReport { pub total: i64, pub auto: i64, pub durable_with_link_ratio: f32 }
pub struct JobCounts { pub pending: i64, pub running: i64, pub quarantined: i64 }
```

All counts use the F§1.2 visibility fragment for the caller. Definitions:
- `durable` = kind in (decision, rule, gotcha, procedure, fact), status active.
- `never_fetched` = durable with no `usage` row or `fetched = 0`; `fetched_30d` = visible with
  `usage.last_used_at > now() - 30 d`; `top` = visible ordered by `fetched DESC, memory_id`.
- `activity.saved` = `count(*) GROUP BY to_char(created_at + make_interval(mins => $tz), 'YYYY-MM-DD')`.
- `stale.expiring_30d` = visible with `expires_at` between now and now + 30 d.
- `links` count rows where both ends are visible; ratio as the step-6 bench metric.
Every `i64`/`u64`/`f32` field carries `#[cfg_attr(feature = "ts", ts(type = "number"))]` (ts-rs
maps 64-bit ints to `bigint` otherwise; all values are < 2^53).

### 1.3 Auth hardening (`crates/server/src/auth.rs`, `crates/store/src/account.rs`, `crates/server/src/error.rs`)

```rust
// store/account.rs
static DUMMY_HASH: OnceLock<String> = OnceLock::new();     // hash_password("cairn-timing-dummy"), same Argon2 params
fn check_password(stored: Option<&str>, given: &str) -> bool {
    let hash = stored.unwrap_or_else(|| DUMMY_HASH.get_or_init(|| hash_password("cairn-timing-dummy").expect("argon2")));
    verify_password(given, hash) && stored.is_some()        // verify runs on every path
}
// login: normalize_email error → check_password(None, pw); row missing → check_password(None, pw);
// disabled → check_password(Some(hash), pw) then Err; all three return the same Forbidden.
```

- Delete `AuthRateLimiter`, `ATTEMPT_LIMIT`, `ATTEMPT_WINDOW`, `PRUNE_AT`, `AppState::throttle`,
  `ApiError::rate_limited` and test `limiter_stops_the_eleventh_try`.
- `error.rs`: `ApiError::session_required()` = 401 `session_required`, used by the `Web` and `Admin`
  extractors for a missing bearer, an unknown token, a device token, or an expired or revoked
  session. Login failure =
  401 `invalid_credentials`, text `invalid account credentials` (unchanged text). Device-token
  failures keep 401 `unauthorized`.
- `EXPIRED_SESSION` text constant stays as the message; the code is the contract.

### 2.3 Generated types (W4)

- Workspace: `ts-rs = { version = "11", features = ["serde-json-impl"] }` as an optional dependency
  of `cairn-core`, `cairn-store`, `cairn-server`; feature `ts = ["dep:ts-rs"]` in each (server's

- Derive with `#[cfg_attr(feature = "ts", derive(ts_rs::TS), ts(export))]` on the types the web

### 2.4 Proxy (`app/api/cairn/[...path]/route.ts` + `lib/proxy.ts`)

```ts
// lib/proxy.ts — pure, unit-tested
export const ALLOWED = ["health", "auth", "devices", "admin", "projects", "memories", "graph", "stats", "forget"] as const;
export function upstreamPath(segments: string[]): string | null {
  if (segments.length === 0 || !ALLOWED.includes(segments[0] as never)) return null;
  if (segments.some((s) => s === "" || s === "." || s === "..")) return null;   // after Next decoding
  return segments.map(encodeURIComponent).join("/");
}
export function cookieMaxAge(expiresAt: number, nowSeconds: number): number {
  return Math.max(0, Math.min(expiresAt - nowSeconds, 60 * 60 * 24 * 30));
}
export function isSessionRequired(status: number, code: unknown): boolean {
  return status === 401 && code === "session_required";
}
```

`route.ts`: `upstreamPath` null → `400 {error:"path not allowed", code:"path_not_allowed"}`;
login/bootstrap: read `expires_at` (number) and set `maxAge = cookieMaxAge(...)`; delete
`SESSION_MAX_AGE`. `lib/session.ts`: delete `SESSION_REQUIRED_MESSAGES`; `isSessionRequired` comes
from `lib/proxy.ts`; `signInFailureMessage(code)` maps `invalid_credentials` → "Email or password
is incorrect.". `lib/cairn.ts` reads `{error, code}` and throws `SessionRequiredError` on
`isSessionRequired(status, code)`.

## 7. Risks

- Without any rate limit, online password guessing is bounded only by Argon2 cost (~50–100 ms per
  try on one core). Owner accepted this (no lockouts); strong passwords (12+ chars, enforced) are
  the defence. Operators who expose the console publicly can add a reverse-proxy limit outside
  Cairn.
- ts-rs output for `#[serde(untagged)] Fields` is a TS union of the per-kind objects; the web must
  narrow by `memory.kind`, as it does today by hand.
- The proxy allowlist must grow with any new top-level route the web needs; the 400 makes a miss
  obvious in development.
