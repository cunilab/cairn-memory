# 0.1.6 Foundation Rewrite — Design Spec (Step 2)

Status: 2b and 2c built on branch `0.1.6` (see the as-built notes below); 2d not started. Base: `c25ad2b`. This spec covers steps 2b–2d.
Later steps that it hands off to: step 3 (MCP cut to 5 tools, CLI cut), step 4 (Rust hooks),
step 5 (SQL-side retrieval), step 7 (web console rework).

Fixed owner decisions (not reopened here): pre-release, so data is wiped and there is no
migration from 0.1.5. PostgreSQL is the only backend. No LLM; the local MiniLM embedding
model stays. Automation first: no human triage queues. Personal or small-team use.

Inputs read: current `crates/*`, `migrations/0001–0018`, `docs/contracts/*`,
`bench/baseline-0.1.6-pre.json`, `scripts/bench.py`, the lifecycle proposal, and the
whole-project audit (audit items are cited as `A#`, proposal sections as `P§`).

---

## 0. Decisions in one screen

| # | Decision | Why |
|---|---|---|
| D1 | All tables live in the Postgres schema `cairn`, in one migration `migrations/0001_foundation.sql`. The 18 old files are deleted. | One schema to read. The old `public.cairn_*` tables cannot collide, and an old database can be detected. |
| D2 | If `public.cairn_memories` exists at startup, the server refuses to start with `pre-0.1.6 database; recreate it`. It never auto-drops data. | Wiping is allowed, but it should be the operator's act. |
| D3 | Migration SQL uses unqualified names. The runner sets `search_path = cairn, public` (tests use `t_<random>, public`). | The same SQL runs in production and in tests that get a schema each. |
| D4 | `supersedes` and `contradicts` are write-time inputs only. They are stored as rows in `links`. No jsonb link arrays on the memory row. | One source of truth for the graph. |
| D5 | Kind and fields are one Rust enum (`Fields`), so a wrong field for a kind cannot be built. Unknown field keys are rejected (400). | The agent gets a clear error. Removes 13 flat optional columns. |
| D6 | Usage counters are in their own table `usage`, not on the memory row. | Hot counter updates do not rewrite the row or its tsvector. |
| D7 | Branches, worktrees, project entities, freshness events, sync pull/deletions, similarity reviews and job quarantine have no table. | No planned feature needs them (§1.3). Branch lists are derived from `memories.repo_branch`. |
| D8 | The similarity review queue is replaced by an automatic `consolidate` job (§6, 2c). | Automation first (A14, P§3.2). The review table is deleted, so near-duplicates need a replacement. |
| D9 | 2b is additive: the new core and the new `crates/store` are built next to the old code, which keeps compiling. 2c switches the server over and deletes the old code. | Each part stays green and can be reviewed alone. |
| D10 | The web console gets only the deletions and type fixes it needs to keep `typecheck/lint/build` green. The real rework is step 7. | The web stays usable without growing step 2. |

## 1. SQL schema (`migrations/0001_foundation.sql`)

### 1.1 Migration runner

- `cairn-store::migrate()` takes `pg_advisory_xact_lock(0x6361_6972)`, checks D2, then runs
  `CREATE SCHEMA IF NOT EXISTS cairn` and `CREATE EXTENSION IF NOT EXISTS vector` (the extension
  lives in `public`).
- It applies each `migrations/NNNN_*.sql` not yet listed in `schema_version`, inside one
  transaction per file. Files are embedded with `include_str!` from a list in `store/src/lib.rs`.
- Pool `after_connect`: `SET search_path = <schema>, public`.

### 1.2 DDL

```sql
CREATE INDEX project_members_person_idx ON project_members (person_id);

-- memory -------------------------------------------------------------------
CREATE TABLE memories (
    memory_id      text PRIMARY KEY,               -- core::new_id("mem")
    owner_id       text NOT NULL REFERENCES accounts,
    project_id     text REFERENCES projects,
    scope          text NOT NULL CHECK (scope IN ('personal','project','global')),
    kind           text NOT NULL CHECK (kind IN
                     ('decision','rule','gotcha','procedure','fact','preference','note','handoff')),
    title          text NOT NULL CHECK (char_length(title) <= 80),
    summary        text NOT NULL CHECK (char_length(summary) <= 240),
    reason         text NOT NULL DEFAULT '',
    fields         jsonb NOT NULL DEFAULT '{}',    -- per-kind object, validated in core
    evidence       text[] NOT NULL DEFAULT '{}',
    evidence_count integer NOT NULL DEFAULT 0,     -- includes evidence merged by consolidate
    evidence_hash  text NOT NULL,                  -- sha256 of sorted evidence
    identity_hash  text NOT NULL,                  -- sha256 of kind,title,summary,reason,fields
    repo           text,                           -- context, from the capturing client
    repo_branch    text,
    repo_worktree  text,
    repo_commit    text,
    status         text NOT NULL DEFAULT 'active'
                     CHECK (status IN ('active','stale','superseded','forgotten')),
    expires_at     timestamptz,                    -- set from kind (§2.3)
    created_at     timestamptz NOT NULL DEFAULT now(),
    updated_at     timestamptz NOT NULL DEFAULT now(),
    search_tsv     tsvector GENERATED ALWAYS AS (
        setweight(to_tsvector('english', title), 'A') ||
        setweight(to_tsvector('english', summary), 'B') ||
        setweight(to_tsvector('english', reason), 'C') ||
        setweight(jsonb_to_tsvector('english', fields, '["string"]'), 'C')
    ) STORED,
    CHECK (scope <> 'project' OR project_id IS NOT NULL)
);
-- visibility pre-filters (step 5 joins search candidates against these)
CREATE INDEX memories_owner_idx   ON memories (owner_id, status, updated_at DESC);
CREATE INDEX memories_project_idx ON memories (project_id, status, updated_at DESC)
    WHERE scope = 'project';
CREATE INDEX memories_global_idx  ON memories (updated_at DESC)
    WHERE scope = 'global' AND status = 'active';
CREATE INDEX memories_branch_idx  ON memories (project_id, repo_branch) WHERE repo_branch IS NOT NULL;
CREATE INDEX memories_search_idx  ON memories USING gin (search_tsv);        -- websearch_to_tsquery
CREATE INDEX memories_expiry_idx  ON memories (expires_at) WHERE expires_at IS NOT NULL;
CREATE UNIQUE INDEX memories_identity_idx                                    -- exact dedupe
    ON memories (owner_id, scope, coalesce(project_id, ''), identity_hash);

CREATE TABLE memory_embeddings (
    memory_id   text PRIMARY KEY REFERENCES memories ON DELETE CASCADE,
    model       text NOT NULL,                     -- e.g. 'all-MiniLM-L6-v2@<rev>'
    source_hash text NOT NULL,                     -- sha256 of core::embedding_text
    embedding   vector(384) NOT NULL,              -- L2-normalized
    created_at  timestamptz NOT NULL DEFAULT now()
);
CREATE INDEX memory_embeddings_hnsw ON memory_embeddings
    USING hnsw (embedding vector_cosine_ops);                                -- step-5 vector top-K

CREATE TABLE entities (                            -- server-derived, deterministic
    memory_id text NOT NULL REFERENCES memories ON DELETE CASCADE,
    kind      text NOT NULL CHECK (kind IN ('file','symbol','command','test','service','term')),
    name      text NOT NULL,                       -- normalized (repo-relative path, lower-case term)
    PRIMARY KEY (memory_id, kind, name)
);
CREATE INDEX entities_lookup_idx ON entities (name, kind);                    -- entity channel + auto-links

CREATE TABLE links (
    source_id  text NOT NULL REFERENCES memories ON DELETE CASCADE,
    target_id  text NOT NULL REFERENCES memories ON DELETE CASCADE,
    relation   text NOT NULL CHECK (relation IN
                 ('relates','causes','fixes','depends_on','supersedes','contradicts')),
    origin     text NOT NULL CHECK (origin IN ('agent','auto')),
    created_at timestamptz NOT NULL DEFAULT now(),
    PRIMARY KEY (source_id, target_id, relation),
    CHECK (source_id <> target_id)
);
CREATE INDEX links_target_idx ON links (target_id, relation);

CREATE TABLE usage (                               -- internal; never shown to agents
    memory_id    text PRIMARY KEY REFERENCES memories ON DELETE CASCADE,
    fetched      integer NOT NULL DEFAULT 0,       -- explicit get/search by an agent only
    helpful      integer NOT NULL DEFAULT 0,
    wrong        integer NOT NULL DEFAULT 0,
    last_used_at timestamptz
);
CREATE TABLE usage_votes (                         -- one row per voter and vote; helpful/wrong = distinct voters
    memory_id text NOT NULL REFERENCES memories ON DELETE CASCADE,
    person_id text NOT NULL REFERENCES accounts,
    vote      text NOT NULL CHECK (vote IN ('helpful','wrong')),
    PRIMARY KEY (memory_id, person_id, vote)
);

-- capture ------------------------------------------------------------------
CREATE TABLE sessions (
    person_id     text NOT NULL REFERENCES accounts,
    session_id    text NOT NULL,                   -- host agent's session id
    project_id    text REFERENCES projects,
    context       jsonb NOT NULL DEFAULT '{}',     -- repo, branch, worktree, commit
    started_at    timestamptz NOT NULL DEFAULT now(),
    ended_at      timestamptz,
    pending_since timestamptz,                     -- has captures not yet distilled
    PRIMARY KEY (person_id, session_id)
);
CREATE INDEX sessions_pending_idx ON sessions (pending_since) WHERE pending_since IS NOT NULL;

CREATE TABLE observations (                        -- raw evidence; never recalled
    person_id   text NOT NULL REFERENCES accounts,
    event_id    text NOT NULL,                     -- client idempotency key
    session_id  text NOT NULL,
    role        text NOT NULL,
    source      text NOT NULL,
    content     text NOT NULL,                     -- redacted, clipped to 2 KiB
    content_hash text NOT NULL,                    -- same event_id with other content = 409
    context     jsonb NOT NULL DEFAULT '{}',       -- WorkContext incl. files/symbols/commands
    captured_at timestamptz NOT NULL DEFAULT now(),
    expires_at  timestamptz NOT NULL,              -- captured_at + 30 days
    PRIMARY KEY (person_id, event_id),
    FOREIGN KEY (person_id, session_id) REFERENCES sessions
);
CREATE INDEX observations_session_idx ON observations (person_id, session_id, captured_at);
CREATE INDEX observations_expiry_idx  ON observations (expires_at);

-- process ------------------------------------------------------------------
CREATE TABLE jobs (
    job_id           text PRIMARY KEY,
    kind             text NOT NULL CHECK (kind IN ('embed','distill','consolidate')),
    job_key          text NOT NULL,
    status           text NOT NULL DEFAULT 'pending'
                       CHECK (status IN ('pending','running','done','quarantined')),
    attempts         integer NOT NULL DEFAULT 0,
    not_before       timestamptz NOT NULL DEFAULT now(),
    claim_id         text,
    lease_expires_at timestamptz,
    last_error       text,
    created_at       timestamptz NOT NULL DEFAULT now(),
    updated_at       timestamptz NOT NULL DEFAULT now(),
    finished_at      timestamptz
);
CREATE UNIQUE INDEX jobs_one_pending ON jobs (kind, job_key) WHERE status = 'pending';
CREATE INDEX jobs_claimable ON jobs (kind, not_before, job_id) WHERE status = 'pending';
CREATE INDEX jobs_lease     ON jobs (lease_expires_at) WHERE status = 'running';
CREATE INDEX jobs_admin     ON jobs (status, updated_at DESC) WHERE status <> 'done';
```

Visibility rule (one SQL fragment in `store/src/memory.rs`, reused by every read):
`status <> 'forgotten' AND (expires_at IS NULL OR expires_at > now()) AND (owner_id = $me OR scope = 'global' OR (scope = 'project' AND project_id IN (SELECT project_id FROM project_members WHERE person_id = $me)))`.

## 2. Rust model (`crates/core/src/memory/`)

### 2.1 Types

```rust
// memory/model.rs
// all enums: #[derive(Clone, Copy, Debug, PartialEq, Eq, Serialize, Deserialize)]
//            #[serde(rename_all = "snake_case")]
pub enum Kind { Decision, Rule, Gotcha, Procedure, Fact, Preference, Note, Handoff }
pub enum Scope { Personal, Project, Global }
pub enum Status { Active, Stale, Superseded, Forgotten }
pub enum Relation { Relates, Causes, Fixes, DependsOn, Supersedes, Contradicts }
pub enum EntityKind { File, Symbol, Command, Test, Service, Term }

#[derive(Clone, Debug, Default, PartialEq, Eq, Serialize, Deserialize)]
pub struct Context {                     // from the client's git state; never redacted
    pub repo: Option<String>,
    pub branch: Option<String>,
    pub worktree: Option<String>,
    pub commit: Option<String>,
}

/// What an agent may send. Everything else is server-derived.
#[derive(Clone, Debug, Deserialize)]
#[serde(deny_unknown_fields)]
pub struct SaveInput {
    pub kind: Kind,                      // `handoff` is rejected: system-only
    pub title: String,                   // 1..=80 chars
    pub summary: String,                 // 1..=240 chars
    #[serde(default)] pub reason: String, // required (non-empty) unless kind == note
    #[serde(default)] pub fields: Option<serde_json::Value>, // parsed by Fields::parse(kind, ..)
    #[serde(default)] pub evidence: Vec<String>,  // <= 20 items, each <= 300 chars
    #[serde(default)] pub supersedes: Option<String>,
    #[serde(default)] pub contradicts: Option<String>,
    #[serde(default)] pub scope: Option<Scope>,   // default: see 2.3
}

/// A stored memory as the server returns it.
#[derive(Clone, Debug, PartialEq, Serialize)]
pub struct Memory {
    pub id: String,
    pub owner: String,
    pub project_id: Option<String>,
    pub scope: Scope,
    pub kind: Kind,
    pub title: String,
    pub summary: String,
    #[serde(skip_serializing_if = "String::is_empty")] pub reason: String,
    pub fields: Fields,                  // serialized as the bare per-kind object
    #[serde(skip_serializing_if = "Vec::is_empty")] pub evidence: Vec<String>,
    pub evidence_count: u32,
    pub context: Context,
    #[serde(skip_serializing_if = "Vec::is_empty")] pub entities: Vec<Entity>,
    #[serde(skip_serializing_if = "Vec::is_empty")] pub links: Vec<Link>, // outgoing + incoming
    pub status: Status,
    pub expires_at: Option<i64>,         // unix seconds
    pub created_at: i64,
    pub updated_at: i64,
    #[serde(skip)] pub evidence_hash: String,
    #[serde(skip)] pub identity_hash: String,
    #[serde(skip)] pub usage: Usage,     // internal only
}

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct Entity { pub kind: EntityKind, pub name: String }

#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
pub struct Link { pub relation: Relation, pub source: String, pub target: String, pub auto: bool }

#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct Usage { pub fetched: u32, pub helpful: u32, pub wrong: u32, pub last_used_at: Option<i64> }
```

```rust
// memory/fields.rs — every per-kind struct is #[serde(default, deny_unknown_fields)]
#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
#[serde(untagged)]                       // Serialize only; kind travels in Memory::kind
pub enum Fields {
    Decision(Decision), Rule(Rule), Gotcha(Gotcha), Procedure(Procedure),
    Fact(Fact), Preference(Preference), Note(Note), Handoff(Handoff),
}
pub struct Decision  { pub context: String, pub alternatives: Vec<String>, pub consequences: String }
pub struct Rule      { pub exceptions: String }
pub struct Gotcha    { pub symptom: String, pub cause: String, pub fix: String }
pub struct Procedure { pub steps: Vec<String>, pub when: String }   // steps ordered
pub struct Fact      { pub source: String }
pub struct Preference{ pub example: String }
pub struct Note      {}
pub struct Handoff   { pub next_steps: Vec<String>, pub open_questions: Vec<String>, pub files: Vec<String> }

impl Fields {
    pub fn parse(kind: Kind, value: Option<serde_json::Value>) -> Result<Self, Error>; // 400 on unknown key
    pub fn kind(&self) -> Kind;
    pub fn to_json(&self) -> serde_json::Value;   // empty strings/arrays omitted
    pub fn text(&self) -> String;                 // for embedding_text and identity
}
```

Limits (core `memory/validate.rs`, enforced before any IO): each string field is at most 1,000
chars, each array at most 20 items of at most 300 chars, and the whole `fields` object is at most
4 KiB. The rule statement and the fact statement from 0.1.5 are folded into `summary`.

### 2.2 Derivation (core, pure)

| Attribute | Rule |
|---|---|
| `id` | `new_id("mem")`: prefix plus 128-bit random, base32 |
| `owner`, `project_id` | the authenticated person; the project from the request `context.project_id` if the person is a member (auto-join as in 0.1.5) |
| `context` | request work context: repo, branch, worktree, commit |
| `entities` | `process::entities::derive(&SaveInput, &WorkContext)`: request `files/symbols/commands/tests/services`, plus repo-relative paths and backticked identifiers found in title/summary/reason/fields; deduplicated, capped at 32 |
| `evidence_count`, `evidence_hash` | count and sha256 of sorted, deduplicated evidence |
| `identity_hash` | sha256 of `kind, title, summary, reason, fields.to_json()` after redaction |
| `status` | `active`; `superseded` when a later save names it in `supersedes`; `stale` when `wrong >= 2`, or `wrong >= 1` from the owner; `forgotten` on forget |
| `expires_at` | by kind (2.3) |
| links | `supersedes`/`contradicts` input become `links` rows with origin `agent`; consolidate adds origin `auto` |

All text is passed through `capture::redact` before hashing and storage (the same denylist as
0.1.5; widening it is A12, not this step).

### 2.3 Kind policy

| Kind | Written by | Default scope | `expires_at` |
|---|---|---|---|
| decision, rule, gotcha, procedure, fact | agent | `project` if the repo is initialized, else `personal` | none |
| preference | agent | `personal` (`project`/`global` rejected) | none |
| note | agent, distill | `personal` | created + 90 d |
| handoff | distill only | `personal` with project_id | created + 14 d; one per (owner, session), upserted |

Forget means `status='forgotten'`. Title, summary, reason, fields and evidence are blanked, and
embedding, entity and link rows are deleted. `identity_hash` stays, so a later save with the same
identity returns 409 `forgotten`. That keeps the 0.1.5 forgotten-items behaviour. Expired rows
are hidden by the visibility rule. The idle sweep hard-deletes memories more than 30 days past
expiry, and observations past `expires_at`.

`TestDb` (`cairn-store` feature `testing`, dev-dependency of store, server and client):
- It reads `CAIRN_TEST_DATABASE_URL`, creates schema `t_<16 hex>`, opens a pool with
  `search_path = t_<..>, public`, and runs `migrate()` into it. Tests run in parallel, each in its
  own schema. No more `#[ignore]` and no database per test.
- `finish().await` drops the schema. A panicking test leaks a schema, which is harmless.
  `scripts/dev_down.sh` removes the volume.
- With `CAIRN_TEST_DATABASE_URL` unset, the test prints `SKIP (no CAIRN_TEST_DATABASE_URL)`
  and returns. If `CAIRN_TEST_REQUIRE_DB=1` (always set in CI), it panics instead. The same rule
  applies to `CAIRN_EMBEDDING_MODEL_DIR` for semantic tests.
- Locally: `scripts/dev_up.sh` (existing docker compose, pgvector pg17 on `127.0.0.1:55432`),
  then `source scripts/dev_env.sh`, which exports `CAIRN_TEST_DATABASE_URL`, then
  `cargo test --workspace`.
- In CI, the `rust-tests` job gets a `pgvector/pgvector:pg17` service and the model download, and
  runs plain `cargo test --workspace --locked` with `CAIRN_TEST_REQUIRE_DB=1`. The separate
  `postgres-tests` job and `ci_postgres_tests.sh` are deleted.

   (`POST /correct`, `memory_correct` and the store `correct` fn are not built.)
