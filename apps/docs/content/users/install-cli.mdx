# Install the CLI

Download and verify the standalone `cairn` client binary for macOS, Linux, or Windows.

Download the binary and `SHA256SUMS` from the [latest GitHub release](https://github.com/cunilab/cairn-memory/releases/latest). See the [repository installation guide](../../../../README.md#2-install-and-configure-the-first-device) for copyable install scripts.

| Platform | Release asset | Checksum command |
| --- | --- | --- |
| macOS Apple silicon | `cairn-aarch64-apple-darwin` | `shasum -a 256` |
| Linux x86-64 | `cairn-x86_64-unknown-linux-musl` | `sha256sum` |
| Linux arm64 | `cairn-aarch64-unknown-linux-musl` | `sha256sum` |
| Windows x86-64 | `cairn-x86_64-pc-windows-msvc.exe` | `Get-FileHash -Algorithm SHA256` |

## Confirm the installed binary

Open a fresh terminal after updating `PATH` and verify the installation:

<Tabs items={['Shell', 'PowerShell']}>
<Tab value="Shell">

```sh
command -v cairn
cairn --version
```

</Tab>
<Tab value="PowerShell">

```powershell
Get-Command cairn
cairn --version
```

</Tab>
</Tabs>

- **Default paths**: Unix scripts install to `~/.local/bin`. PowerShell installs to `%LOCALAPPDATA%\cairn\bin` and updates the user `PATH`.
- **Source build**: Alternatively, compile from source with `cargo build --release -p cairn-client`.
- **Next step**: With `cairn` on your `PATH`, [connect an agent](agents/index.md).
