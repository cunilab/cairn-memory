# Cairn Memory 0.1.7 release notes

Maintenance release delivering absolute ranking scores, deduplication improvements, and cleaner session handoffs.

Ranking amendment: [Architecture decisions](../../technical/index.mdx#decisions-and-why).

## What changed for users

- **Absolute ranking scores**: Scores reflect word coverage and semantic similarity rather than relative fused positions. Lexical hits with embeddings require cosine similarity ≥ 0.35.
- **Feedback un-staling**: One vote per person. A `helpful` vote reverses an earlier `wrong` vote and reactivates feedback-staled memories (memories missing files remain stale).
- **Cleaner deduplication**: Two saves matching kind, title, summary, and fields are treated as one identity; updating the reason via `supersedes` succeeds without creating duplicates.
- **Filtered handoffs**: Raw command pastes, markdown headings, quotes, and code fences are omitted from session handoffs.
- **Token rotation retry**: `cairn mcp` re-reads configuration and retries once on HTTP 401, allowing token rotation without restarting the agent host.
- **Topic notes on Read**: File topic injection triggers on file reads as well as edits.

## Upgrade steps

1. Upgrade server and client versions together. No database wipe or migration required.
2. Run `cairn update` on each client machine.
3. Verify the installation with `cairn doctor`.
