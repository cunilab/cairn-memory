# Cairn Memory 0.1.10 release notes

Feature release adding layered automatic recall (L0–L3), memory trust ratings, pins, a shared skill library, and Claude Code memory import.

## Major additions

- **Layered recall (L0–L3)**:
  - **L0 Identity** (600 B): Personal and project pins (oldest first).
  - **L1 Essential** (1,200 B): Handoffs, preferences, rules, decisions, gotchas.
  - **L2 Contextual** (300 B/card): File topics, command warnings, error recall, prompts.
  - **L3 Search**: Explicit `memory_search` queries.
- **Trust ratings**: Cards labeled `doubted`, `new`, `proven`, or `normal` based on verification and voting counters.
- **Global skill library**: Added `skill_search`, `skill_get`, `skill_save`, and `skill_feedback` for procedural knowledge.
- **New agent integrations**: Added `--agent grok`, `--agent antigravity`, and `--agent hermes`.
- **Claude Code import**: `cairn import claude-memory` converts native Claude memories into Cairn records and protects native memory paths.
- **Project archiving**: Archive projects from the console to hide memories from agent search while preserving data.

## Database migrations

The server applies 11 migrations on startup:

| Migration | Purpose |
| --- | --- |
| `0015_memory_detail` | Optional 8KB detail field and text index |
| `0016_project_archive` | Project archive timestamp |
| `0017_device_agents` | CHECK constraint update for Grok and Antigravity |
| `0018_memory_usage` | Shown and detail-open counter tracking |
| `0019_session_shown` | Per-session automatic recall ledger |
| `0020_device_agent_hermes` | CHECK constraint update for Hermes |
| `0021_push_usage` | Per-person push and use ledger |
| `0022_memory_pins` | Memory pin timestamp |
| `0023_hermes_chat` | Chat-scoped personal memory tag |
| `0024_hermes_route_privacy` | Redact obsolete sender metadata from chat logs |
| `0025_skills` | Global skill tables, versions, and votes |

## Upgrade steps

1. Back up database. Deploy the server before the web console.
2. Run `cairn update`, then run `cairn setup <agent>` once for each configured agent.
3. In Claude Code projects with existing memories, run `cairn import claude-memory`.
4. Run `cairn doctor` to confirm configuration.
