# Cairn Memory 0.1.12 release notes

More reliable agent handoffs and recall, native Hermes gateway tools, and larger memory text limits.

## Changes

- **Fixes from real use**: Improve Grok file recall, save reminders, and evidence-only command handling. Handoffs now include the task, files, last run and next step. Failed-command recall uses Grok and Hermes output and can find gotchas by file; Hermes carries a save ask into the next turn.
- **Hermes gateway**: Keep gateway tools unavailable until the serving process has loaded the chat hook. After `cairn setup hermes --gateway`, restart the Hermes gateway and run `/new`.
- **Memory text limits**: Titles up to 80 characters and summaries up to 240 remain suggested lengths; hard limits are now 200 and 1,000 characters.
- **Privacy and provenance**: Redact Bearer tokens and record session provenance for saved and distilled memories.
- **Search**: Add project, time and version filters, match reasons, and narrower memory retrieval.

## Database changes

Migrations 0026–0028 add session provenance and pin ordering, opt-in retrieval traces, and the 200 / 1,000 character hard limits. They are additive; migration 0028 replaces only the title and summary checks and does not rewrite existing memories. At startup, a one-time evidence-entity backfill runs in batches and records completion under `backfill_evidence_entities`. A dry run on a production copy took 29 ms; memory rows were unchanged.

## Upgrade

Back up the database, then upgrade the server and clients together. A 0.1.12 client requires a 0.1.12 server. Migrations run at server startup; there is no downgrade path. After updating Hermes, run `cairn setup hermes --gateway`, start the Hermes gateway process again, then run `/new`.

See the [upgrade guide](../upgrade.md), [Hermes gateway setup](../agents/hermes-gateway.md) and [migration details](../../technical/release-process.md).
