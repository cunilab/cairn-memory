# Cairn Memory 0.1.11 release notes

Hermes Agent native memory provider integration, clean file removal, and dependency security updates.

## Major changes

- **Native Hermes memory provider**: Cairn integrates as Hermes Agent's external memory provider (`memory.provider: cairn-memory`), handling prompt prefetch, checkpoints, session finalization, and native tool execution.
- **Requires Hermes v2026.4.23+**: Enforces minimum version supporting `transform_tool_result` and gateway session contexts.
- **Clean removal**: `cairn setup <agent> --remove` completely removes empty files, configuration entries, bytecode caches, and empty parent directories.
- **Console security update**: Resolves `minimatch` 11.0.9 security alert.

## Upgrade steps

1. Upgrade server and web console (no database migrations in this release).
2. Run `cairn update` on each client device.
3. Update Hermes to v2026.4.23+ (`hermes update`), then re-run `cairn setup hermes` for each profile (use `HERMES_HOME=/path` and `--gateway` as needed).
4. Verify with `hermes memory status` and `cairn doctor`.

See [hook setup](../agents/index.md#setup), [Hermes gateway](../agents/hermes-gateway.md#hermes-gateway) and [Hermes provider tools](../reference/mcp.md#hermes-provider-tools).
