# Cairn Memory 0.1.9 release notes

Release introducing project-attached distillation, non-Git project initialization, Stop reminders, automated Fixes, and retained memory history.

## Key enhancements

- **Project distillation**: Distilled notes automatically attach to recognized projects as candidate memories (`new`).
- **Non-Git init & auto-attach**: `cairn init` initializes non-Git folders. Checkouts whose remote matches exactly one existing project membership automatically attach.
- **Stop reminder**: In recognized projects, after file edits or corrections, the Stop hook prompts the agent once to save up to three reusable notes.
- **Project digests**: Sessions with file changes produce a searchable digest summarizing modified files and the final status of test runs.
- **Automated Fixes**: Server detectors identify configuration drift, uncredited memories, and hook issues. Administrators review and apply fixes in the console.
- **Memories never expire by age**: Stale and superseded memories remain retrievable with lower ranking; forgotten memories remain hidden.
- **Derived aliases**: Memories support up to 5 aliases for enhanced lexical search.

## Database migrations

The server applies 9 migrations on startup:

| Migration | Purpose |
| --- | --- |
| `0006_agent_instructions` | Project instruction overrides |
| `0007_memory_rank` | Candidate and normal rank schema |
| `0008_proof_count` | Proof count tracking and backfill |
| `0009_memory_aliases` | Alias table and lexical index |
| `0010_session_outcome` | Session distillation outcome tracking |
| `0011_fixes` | Fixes, lookup logs, and device status tables |
| `0012_always_active` | Search index including superseded memories |
| `0013_link_origin_system` | System link origin and handoff backfill |
| `0014_memory_owner_project_created` | Project session reporting index |

## Upgrade steps

1. Back up PostgreSQL database. Update server and clients together.
2. Run `cairn update` on each machine, then rerun `cairn setup <url> --agent <agent>` to install updated hooks.
3. Run `cairn doctor` to verify health.
