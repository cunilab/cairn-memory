# Cairn Memory 0.1.6 release notes

Major architectural upgrade introducing native Rust hooks, 5 streamlined MCP tools, and local MiniLM embeddings.

Design record: [Architecture decisions](../../technical/index.mdx#decisions-and-why).

## What changed for users

- **5 MCP tools** (replacing 38 legacy tools): `memory_search`, `memory_get`, `memory_save`, `memory_feedback`, `memory_forget`.
- **Native Rust hooks**: Sessions begin with a bounded brief, and agents receive targeted memories during execution without Python dependencies.
- **Automated memory management**: Automatic linking, duplicate consolidation, stale-marking, and cross-session distillation.
- **Embedded vector search**: Built-in `all-MiniLM-L6-v2` (384 dimensions) runs locally in the server. Benchmark (43 queries among 2,000 distractors): hit@5 0.651, 14/14 off-topic queries empty, ~133 token search replies (`bench/after-0.1.6-final-v2.json`).
- **New web console**: Dashboard, Memories, Activity, Projects, Graph, Settings, and device management.
- **Supported agents**: Claude Code, Codex, and OpenCode.

## Breaking changes

- **Fresh database required**: 0.1.6 uses a redesigned PostgreSQL schema. The server refuses to start on pre-0.1.6 stores; deploy against a fresh database.
- **Synchronized updates**: Server and clients must be updated to 0.1.6 together.
- **Legacy Python hooks removed**: Replaced entirely by compiled Rust hooks.
- **Tool consolidation**: Legacy reflect, context, lesson, and diagnosis tools are replaced by `memory_search` with kind filters.

## Upgrade steps

1. Deploy the 0.1.6 server against a **fresh PostgreSQL database**.
2. Update the local client: `cairn update`.
3. Connect your agent: `cairn setup <url> --agent claude|codex|opencode`.
4. Remove legacy `~/.config/cairn/env` sourcing lines from shell profiles (`~/.zshrc`, `~/.zprofile`).
5. Run `cairn doctor` to verify all checks pass.
