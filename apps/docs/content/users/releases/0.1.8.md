# Cairn Memory 0.1.8 release notes

Bug fix release correcting dot-directory entity matching and surfacing explicit stale cause explanations.

## What changed for users

- **Dot-directory entity fix**: Fixed an issue where paths with leading dot-directories (e.g. `.cairn/project.json`, `.github/ci.yml`) stripped the dot during entity derivation, causing incorrect `stale` (missing) classifications.
- **Detailed stale causes**: Memory cards, get records, and feedback responses now include `stale_cause: "feedback" | "missing"` explaining why a record was marked stale.
- **Transparent feedback feedback**: A `helpful` vote on a memory marked stale by repository checks now returns an explicit message explaining that file absence cannot be cleared by feedback.

## Upgrade steps

1. Upgrade server and clients together. No database migrations required.
2. Run `cairn update` on client machines.
3. Verify status with `cairn doctor`.
